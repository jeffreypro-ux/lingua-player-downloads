# 墨词 Lingua Player

本地双语视频学习工具。优先导入现成中英双语字幕，几秒钟开始学习；没有字幕时可以使用本地 AI 自动生成。

## 启动

完整解压 ZIP 后双击 `start.bat`。程序自带运行环境，不需要另外安装 Node；浏览器会自动打开实际使用的本地地址。

请不要直接在 ZIP 压缩包预览窗口中运行。如果启动失败，命令窗口会保留错误信息，便于截图排查。

也可以在当前目录执行：

```powershell
node server.js
```

## 当前版本

- 本地视频上传与播放
- 柔和模糊、轻度压暗的视频背景
- 双语逐句字幕与歌词式逐词高亮
- 左右方向键逐句切换，空格播放/暂停
- 导入一份中英双语 SRT / VTT / ASS / SSA 字幕
- 自动区分同一条字幕中的英文和中文
- 四级、六级、雅思关键词筛选演示
- 响应式桌面与移动端界面

## 本地自动识别

字幕导入不需要模型。选择视频后，导入网上下载的中英双语 SRT、VTT、ASS 或 SSA 文件即可立即学习。

找不到字幕时，可以打开右上角“AI 识别（可选）”，准备 whisper.cpp 识别管线和 OPUS-MT 英译中管线。组件总量约 1GB，安装后可以断网运行。

如一键安装失败，也可以把以下文件手动放入指定位置：

```text
tools/ffmpeg.exe
tools/whisper/whisper-cli.exe
tools/models/ggml-small.en.bin
```

也可以通过环境变量 `LINGUA_FFMPEG`、`LINGUA_WHISPER`、`LINGUA_MODEL` 指向已有文件。模型与工具缺失时，播放器仍可正常使用，并支持导入 SRT / VTT。

本地翻译采用量化 OPUS-MT 模型，安装后可以断网运行。

## 视频格式

- 最推荐：MP4，H.264 视频编码 + AAC 音频编码
- 通常可用：MOV、WebM
- 可用于字幕识别但画面可能无法在浏览器预览：MKV、H.265/HEVC、DTS
- 单个文件上限：8GB；1080p 已足够，识别效果主要取决于音频清晰度
